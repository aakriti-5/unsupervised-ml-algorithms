Unsupervised Machine Learning Algorithms

This repository contains my implementations and practical experiments with important Unsupervised Machine Learning algorithms using Python and Scikit-learn.

Algorithms Covered
1. K-Means Clustering

K-Means is a clustering algorithm that divides data points into a predefined number of clusters based on their similarity.

Topics covered:

Data preprocessing
Feature scaling
K-Means clustering
Choosing the number of clusters
Cluster visualization
2. Hierarchical Clustering

Hierarchical clustering creates a hierarchy of clusters and can be visualized using a dendrogram.

Topics covered:

Data preprocessing
Feature scaling
Dendrogram
Agglomerative Clustering
Cluster visualization
3. DBSCAN Clustering

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) groups points based on their density and can identify outliers/noise.

Topics covered:

Data preprocessing
Feature scaling
DBSCAN
eps and min_samples
Outlier detection
Cluster visualization
